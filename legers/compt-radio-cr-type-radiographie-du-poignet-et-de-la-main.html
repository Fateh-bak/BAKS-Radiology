Mode d'emploi

TexteMode d'emploi
Formulations à adapter ; champs entre crochets à compléter. Provenance : [S mm/aa] service ; [S+L] service enrichi ; [L] littérature / standards internationaux. Radius distal : inclinaison radiale (normale ~22°), bascule palmaire (~11°), index radio-ulnaire (variance ulnaire). Arcs de Gilula, espace scapho-lunaire (< 3 mm). Scaphoïde : incidences dédiées (Schneck) ; fracture occulte : TDM / IRM.

1. Normal et contrôles

▸ Poignet normal [S+L]

Texte▸ Poignet normal [S+L]
Résultats : Bonne minéralisation. Arcs carpiens de Gilula harmonieux ; interlignes radio-carpien et médio-carpien réguliers ; espace scapho-lunaire non élargi ; index radio-ulnaire neutre. Absence de trait de fracture. Conclusion : Radiographie du poignet sans anomalie décelable.

▸ Main / doigts normaux [S+L]

Texte▸ Main / doigts normaux [S+L]
Résultats : Métacarpiens et phalanges de contours réguliers ; interlignes métacarpo-phalangiens et interphalangiens réguliers ; absence de trait de fracture ou de luxation. Conclusion : Radiographie de la main [du x doigt] sans anomalie décelable.

▸ Contrôle sous plâtre / brochage [S+L]

Texte▸ Contrôle sous plâtre / brochage [S+L]
Résultats : Immobilisation plâtrée en place ; fracture du radius distal [réduite] : inclinaison radiale [x]°, bascule [palmaire x]°, index radio-ulnaire [x] mm ; [broches en place sans migration] ; absence de déplacement secondaire ; [cal en formation]. Conclusion : Fracture [x] en bonne position sous plâtre, sans déplacement secondaire.
