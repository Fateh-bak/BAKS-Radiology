Mode d'emploi

TexteMode d'emploi
Formulations à adapter ; champs entre crochets à compléter. Provenance : [S mm/aa] service ; [S+L] service enrichi ; [L] littérature / standards internationaux. Clichés : face, profil, profil centré L5–S1, ¾ (isthmes), dynamiques si instabilité. Décompte vertébral (anomalie transitionnelle : Castellvi). Spondylolisthésis : Meyerding (grade I < 25 % … IV 75–100 %, V spondyloptose).

1. Normal et contrôles

▸ Rachis lombo-sacré normal [S+L]

Texte▸ Rachis lombo-sacré normal [S+L]
Résultats : Bonne minéralisation. Statique frontale respectée ; lordose lombaire conservée. Absence d'anomalie transitionnelle. Corps vertébraux de hauteur normale ; espaces intervertébraux conservés. Absence de lyse isthmique ou de spondylolisthésis. Articulations sacro-iliaques sans anomalie. Conclusion : Radiographie du rachis lombo-sacré sans anomalie décelable.

▸ Contrôle post-opératoire (arthrodèse) [S+L]

Texte▸ Contrôle post-opératoire (arthrodèse) [S+L]
Résultats : Arthrodèse [L4–L5] par vis pédiculaires et tiges [et cage intersomatique] en place ; absence de démontage, de rupture ou de liseré péri-vis ; alignement conservé ; [fusion postéro-latérale en cours]. Conclusion : Matériel d'arthrodèse [L4–L5] en place, sans complication décelable.

2. Pathologies

▸ Discarthrose lombaire [S+L]

Texte▸ Discarthrose lombaire [S+L]
Résultats : Pincement discal [L4–L5 et L5–S1] avec ostéophytose marginale et sclérose des plateaux ; [arthrose inter-apophysaire postérieure L4–L5 et L5–S1] ; [rétrolisthésis de x mm]. Conclusion : Discarthrose lombaire [étagée prédominant en L4–L5 et L5–S1].

▸ Spondylolisthésis [S+L]

Texte▸ Spondylolisthésis [S+L]
Résultats : Antélisthésis de [L5 sur S1] de [x] % [par lyse isthmique bilatérale de L5 (vue sur les ¾)] / [dégénératif de L4 sur L5 sur arthrose inter-apophysaire]. Conclusion : Spondylolisthésis [isthmique / dégénératif] [L5–S1] grade [x] de Meyerding.

▸ Anomalie transitionnelle [L]

Texte▸ Anomalie transitionnelle [L]
Résultats : [Sacralisation de L5 : apophyse transverse [gauche] méga-transverse articulée avec l'aileron sacré] / [lombalisation de S1] ; [spina bifida occulta de S1]. Conclusion : Anomalie transitionnelle lombo-sacrée [Castellvi type x] ; [décompte à reporter pour l'IRM].

▸ Tassement / fracture [L]

Texte▸ Tassement / fracture [L]
Résultats : Tassement de [L1] de [x] % (Genant [x]), [recul du mur postérieur]. Conclusion : Tassement de [L1] [récent probable] : [TDM / IRM].

▸ Sacro-iliite [L]

Texte▸ Sacro-iliite [L]
Résultats : Articulations sacro-iliaques [élargies, érosions, sclérose sous-chondrale (stade x de New York)]. Conclusion : Sacro-iliite [bilatérale] stade [x] [évocatrice de spondylarthrite].

3. Autres situations

▸ Arthrodèse : complications [L]

Texte▸ Arthrodèse : complications [L]
Résultats : [Liseré péri-vis > 2 mm / rupture de tige / migration de cage / pseudarthrose / dégénérescence du segment adjacent avec listhésis de x mm]. Conclusion : [Descellement / rupture / pseudarthrose / syndrome jonctionnel] ; TDM.

▸ Spondylodiscite [L]

Texte▸ Spondylodiscite [L]
Résultats : Pincement discal [L3–L4] avec érosion floue des plateaux adjacents, [fuseau des psoas]. Conclusion : Spondylodiscite [L3–L4] suspectée ; IRM, hémocultures.

▸ Fracture-tassement traumatique (burst) [L]

Texte▸ Fracture-tassement traumatique (burst) [L]
Résultats : Fracture comminutive du corps de [L1], recul du mur postérieur, élargissement de l'espace interpédiculaire. Conclusion : Fracture-éclatement de [L1] (instable) ; TDM.

▸ Fracture de Chance [L]

Texte▸ Fracture de Chance [L]
Résultats : Trait horizontal traversant [le corps, les pédicules et l'arc postérieur de L2], ouverture postérieure. Conclusion : Fracture de Chance [L2] (flexion-distraction) ; TDM, rechercher une lésion digestive.

▸ Instabilité sur clichés dynamiques [L]

Texte▸ Instabilité sur clichés dynamiques [L]
Résultats : Translation de [x] mm (> 4 mm) de [L4] sur [L5] entre flexion et extension, [angulation > 10°]. Conclusion : Instabilité segmentaire [L4–L5].

▸ Métastases / myélome [L]

Texte▸ Métastases / myélome [L]
Résultats : [Lésions lytiques ou condensantes des corps vertébraux / vertèbre borgne / vertèbre ivoire]. Conclusion : Lésions vertébrales suspectes ; IRM, bilan.

▸ Canal lombaire étroit (signes indirects) [L]

Texte▸ Canal lombaire étroit (signes indirects) [L]
Résultats : Arthrose inter-apophysaire postérieure hypertrophique étagée, pédicules courts, [spondylolisthésis dégénératif]. Conclusion : Signes indirects de canal lombaire étroit ; IRM si radiculalgie / claudication.
