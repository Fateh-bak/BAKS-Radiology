Mode d'emploi

TexteMode d'emploi
Formulations à adapter ; champs entre crochets à compléter. Provenance : [S mm/aa] service ; [S+L] service enrichi ; [L] littérature / standards internationaux. Toujours inclure les deux articulations adjacentes. Fracture : siège, trait, déplacement (translation, angulation, raccourcissement, rotation). Consolidation : score RUST (4 corticales). Lésion osseuse : Lodwick (zone de transition, réaction périostée).

1. Normal et contrôles

▸ Os long normal [S+L]

Texte▸ Os long normal [S+L]
Résultats : Bonne minéralisation. [Humérus / fémur / tibia et fibula] de contours réguliers, sans trait de fracture, sans lésion lytique ou condensante ni réaction périostée ; articulations adjacentes sans anomalie. Conclusion : Radiographie [de x] sans anomalie décelable.

Conclusion : Ostéosynthèse en place ; consolidation [en cours / acquise / retard de consolidation].
