Mode d'emploi

TexteMode d'emploi
Formulations à adapter ; champs entre crochets à compléter. Provenance : [S mm/aa] service ; [S+L] service enrichi ; [L] littérature / standards internationaux. Frontal : courbures (vertèbres limites, sommet, angle de Cobb), rotation (Nash-Moe), bascule pelvienne, équilibre frontal (fil à plomb C7 / ligne sacrée médiane). Sagittal : cyphose T4–T12, lordose L1–S1, paramètres pelviens (incidence, pente sacrée, version), SVA. Maturité : Risser (0–5), cartilage triradié. Scoliose : Cobb ≥ 10° avec rotation.
