Mode d'emploi

TexteMode d'emploi
Formulations à adapter ; champs entre crochets à compléter. Provenance : [S mm/aa] service ; [S+L] service enrichi ; [L] littérature / standards internationaux. Clichés : face debout (niveaux), face couché, coupoles (pneumopéritoine). Analyse : gaz digestifs (répartition, calibre : grêle < 3 cm, côlon < 6 cm, cæcum < 9 cm), niveaux, gaz extra-digestifs, opacités calciques, ombres des psoas et reins, squelette. L'ASP est remplacé par la TDM dans la plupart des indications.

1. Normal et contrôles

▸ ASP normal [S+L]

Texte▸ ASP normal [S+L]
Résultats : Répartition normale des gaz digestifs, sans distension ni niveau hydro-aérique pathologique ; absence de pneumopéritoine ; absence d'opacité calcique se projetant sur les aires rénales et le trajet des uretères ; ombres des psoas visibles ; squelette sans anomalie. Conclusion : Abdomen sans préparation sans anomalie décelable.

▸ Contrôle de corps étranger / sonde [S+L]

Texte▸ Contrôle de corps étranger / sonde [S+L]
Résultats : Corps étranger [radio-opaque de x mm (pile bouton / pièce)] se projetant [dans l'estomac / le cadre colique] ; [progression depuis le cliché du x] ; [sonde x en place]. Conclusion : Corps étranger [intra-gastrique / en progression] [sans signe de complication].

▸ Fécalome / stase stercorale [L]

Texte▸ Fécalome / stase stercorale [L]
Résultats : Abondante stase stercorale [du cadre colique / rectale], [fécalome rectal de x cm]. Conclusion : Stase stercorale [importante].

2. Urgences

▸ Occlusion du grêle [L]

Texte▸ Occlusion du grêle [L]
Résultats : Anses grêles distendues ([x] cm), centrales, à valvules conniventes, avec niveaux hydro-aériques plus larges que hauts ; côlon [peu ou pas aéré]. Conclusion : Syndrome occlusif du grêle : TDM abdominale.

▸ Occlusion colique / volvulus [L]

Texte▸ Occlusion colique / volvulus [L]
Résultats : Distension colique [jusqu'au x] ([cæcum x cm]) avec niveaux hauts et étroits ; [anse sigmoïdienne en « grain de café » / « U inversé »]. Conclusion : Occlusion colique [évocatrice de volvulus du sigmoïde] : TDM.

▸ Pneumopéritoine [L]

Texte▸ Pneumopéritoine [L]
Résultats : Croissant gazeux sous-diaphragmatique [bilatéral] sur le cliché des coupoles ; [signe de Rigler]. Conclusion : Pneumopéritoine : perforation d'organe creux.

▸ Lithiase radio-opaque [L]

Texte▸ Lithiase radio-opaque [L]
Résultats : Opacité calcique de [x] mm se projetant [sur l'aire rénale droite / le trajet urétéral pelvien gauche / l'aire vésicale]. Conclusion : Opacité évocatrice de lithiase [x] [à confirmer par échographie / TDM].

▸ Enfant : invagination / entérocolite / NEC [L]

Texte▸ Enfant : invagination / entérocolite / NEC [L]
Résultats : [Absence d'aération de la fosse iliaque droite, image en cocarde] / [pneumatose pariétale, aéroportie]. Conclusion : [Arguments pour une invagination : échographie] / [entérocolite ulcéro-nécrosante : pneumatose].

3. Autres situations

▸ Lithiase vésiculaire radio-opaque [L]

Texte▸ Lithiase vésiculaire radio-opaque [L]
Résultats : Opacités calciques [facettées, groupées] de l'hypochondre droit. Conclusion : Lithiase vésiculaire calcifiée probable ; échographie.

▸ Calcifications pancréatiques [L]

Texte▸ Calcifications pancréatiques [L]
Résultats : Calcifications punctiformes en projection de l'aire pancréatique (L1–L2). Conclusion : Calcifications pancréatiques (pancréatite chronique calcifiante).

▸ Calcifications vasculaires / anévrisme aortique [L]

Texte▸ Calcifications vasculaires / anévrisme aortique [L]
Résultats : Calcifications pariétales de l'aorte abdominale dessinant une dilatation de [x] cm. Conclusion : Calcifications aortiques [avec suspicion d'anévrisme : échographie / angio-TDM].

▸ Néphrocalcinose [L]

Texte▸ Néphrocalcinose [L]
Résultats : Calcifications multiples en projection des pyramides rénales bilatérales. Conclusion : Néphrocalcinose médullaire.

▸ Calcifications pelviennes [L]

Texte▸ Calcifications pelviennes [L]
Résultats : [Phlébolithes ronds à centre clair pelviens] / [calcification « en pop-corn » (myome calcifié)] / [calcification dentaire (tératome)]. Conclusion : [Phlébolithes / myome calcifié / tératome à évoquer] ; [échographie selon le contexte].

▸ Ingestion de pile bouton / aimants [L]

Texte▸ Ingestion de pile bouton / aimants [L]
Résultats : Corps étranger rond radio-opaque [à double contour (pile bouton)] en projection [œsophagienne / gastrique / intestinale] / [aimants multiples]. Conclusion : [Pile bouton œsophagienne : extraction endoscopique en urgence / gastrique : surveillance selon l'âge et la taille] ; [aimants multiples : avis chirurgical].

▸ Body packing [L]

Texte▸ Body packing [L]
Résultats : Multiples corps étrangers ovoïdes de densité homogène, à contour dense ou halo gazeux, en projection du tube digestif. Conclusion : Aspect compatible avec un transport intracorporel de stupéfiants (body packing) ; TDM sans injection.

▸ Iléus réflexe / anse sentinelle [L]

Texte▸ Iléus réflexe / anse sentinelle [L]
Résultats : Aération [d'une anse grêle isolée de la FID / colique droite] sans niveaux nombreux. Conclusion : Anse sentinelle (iléus réflexe) [appendicite / pancréatite / colique néphrétique à rechercher].

▸ Colectasie / colite aiguë grave [L]

Texte▸ Colectasie / colite aiguë grave [L]
Résultats : Dilatation du côlon transverse à [x] cm (> 6 cm), [perte des haustrations, îlots muqueux]. Conclusion : Colectasie [mégacôlon toxique à évoquer dans le contexte] ; TDM.

▸ Pneumatose intestinale / aéroportie [L]

Texte▸ Pneumatose intestinale / aéroportie [L]
Résultats : Clartés gazeuses linéaires ou bulleuses pariétales [des anses grêles / du côlon] ; [clartés arborescentes en projection hépatique périphérique]. Conclusion : [Pneumatose pariétale / aéroportie] : ischémie digestive / entérocolite nécrosante à évoquer ; TDM.

▸ Contrôle de sonde / cathéter / drain [L]

Texte▸ Contrôle de sonde / cathéter / drain [L]
Résultats : [Sonde de gastrostomie / sonde naso-jéjunale / cathéter de dialyse péritonéale] en projection [x], [extrémité x], [sans coudure]. Conclusion : [Matériel] en position correcte / [malposition x].

▸ Occlusion néonatale [L]

Texte▸ Occlusion néonatale [L]
Résultats : [Image en « double bulle » sans aération d'aval (atrésie duodénale)] / [distension grêlique, absence d'aération colique (atrésie iléale / iléus méconial)] / [microcôlon]. Conclusion : Occlusion néonatale [haute / basse] ; avis chirurgical, opacification.

▸ Entérocolite ulcéro-nécrosante (nouveau-né) [L]

Texte▸ Entérocolite ulcéro-nécrosante (nouveau-né) [L]
Résultats : Distension gazeuse, épaississement pariétal, pneumatose [linéaire / bulleuse], [aéroportie], [pneumopéritoine (signe du football)]. Conclusion : ECUN [stade x de Bell] ; surveillance radiographique rapprochée.
