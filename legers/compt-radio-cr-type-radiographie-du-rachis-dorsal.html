Mode d'emploi

TexteMode d'emploi
Formulations à adapter ; champs entre crochets à compléter. Provenance : [S mm/aa] service ; [S+L] service enrichi ; [L] littérature / standards internationaux. Clichés de face et de profil. Cyphose dorsale normale 20–45° (T4–T12). Tassement : classification semi-quantitative de Genant (grade 1 : 20–25 % ; 2 : 25–40 % ; 3 : > 40 %).

1. Normal

▸ Rachis dorsal normal [S+L]

Texte▸ Rachis dorsal normal [S+L]
Résultats : Bonne minéralisation. Statique frontale respectée ; cyphose dorsale physiologique. Corps vertébraux de hauteur normale ; espaces discaux conservés ; pédicules visibles. Ligne para-vertébrale non élargie. Conclusion : Radiographie du rachis dorsal sans anomalie décelable.

2. Pathologies

▸ Tassement vertébral [S+L]

Texte▸ Tassement vertébral [S+L]
Résultats : Tassement [cunéiforme antérieur] de [T12], réduction de hauteur de [x] % (Genant [x]), [mur postérieur respecté / recul du mur postérieur], [ostéopénie diffuse]. Conclusion : Tassement [ostéoporotique probable] de [T12] grade [x] ; [IRM si caractère récent ou suspect (pédicule effacé, convexité du mur postérieur)].

▸ Hypercyphose / maladie de Scheuermann [L]

Texte▸ Hypercyphose / maladie de Scheuermann [L]
Résultats : Hypercyphose dorsale ([x]°) ; aspect cunéiforme ≥ 5° d'au moins trois vertèbres consécutives, irrégularités des plateaux, nodules de Schmorl. Conclusion : Dystrophie rachidienne de croissance (maladie de Scheuermann).

▸ Arthrose / hyperostose [L]

Texte▸ Arthrose / hyperostose [L]
Résultats : Ostéophytose antérieure [en coulée, sur au moins 4 vertèbres contiguës, prédominant à droite], disques préservés. Conclusion : [Spondylose / hyperostose vertébrale ankylosante (maladie de Forestier)].

▸ Lésion lytique / spondylodiscite [L]

Texte▸ Lésion lytique / spondylodiscite [L]
Résultats : [Effacement d'un pédicule (« vertèbre borgne ») de x] / [pincement discal avec érosion des plateaux adjacents de x–y, fuseau para-vertébral]. Conclusion : [Lésion vertébrale suspecte / spondylodiscite] : IRM.

3. Autres situations

▸ Fracture traumatique (charnière) [L]

Texte▸ Fracture traumatique (charnière) [L]
Résultats : Tassement [cunéiforme] de [T12] [de x %], [recul du mur postérieur], [écart interpédiculaire augmenté (burst)]. Conclusion : Fracture [x] de [T12] [stable / instable : TDM].

▸ Métastases vertébrales [L]

Texte▸ Métastases vertébrales [L]
Résultats : Effacement d'un pédicule (« vertèbre borgne ») de [T8], [tassement asymétrique], [lésions condensantes multiples]. Conclusion : Lésions vertébrales d'allure secondaire ; IRM du rachis et bilan.

▸ Mal de Pott [L]

Texte▸ Mal de Pott [L]
Résultats : Pincement discal [T8–T9] avec destruction des plateaux, cyphose angulaire, fuseau para-vertébral [calcifié]. Conclusion : Spondylodiscite tuberculeuse (mal de Pott) [T8–T9] probable ; IRM.

▸ Ostéoporose (Genant multiple) [L]

Texte▸ Ostéoporose (Genant multiple) [L]
Résultats : Hypertransparence osseuse diffuse, accentuation des travées verticales, tassements [T7, T11] grades [x et x]. Conclusion : Ostéoporose avec tassements multiples ; ostéodensitométrie.

▸ Spondylarthrite ankylosante [L]

Texte▸ Spondylarthrite ankylosante [L]
Résultats : Syndesmophytes fins verticaux, mise au carré des vertèbres, [colonne bambou], [ankylose des articulaires costo-vertébrales]. Conclusion : Atteinte rachidienne de spondylarthrite ankylosante.

▸ Cyphose congénitale / hémivertèbre [L]

Texte▸ Cyphose congénitale / hémivertèbre [L]
Résultats : Hémivertèbre [T10 droite] avec cyphoscoliose localisée. Conclusion : Malformation vertébrale (hémivertèbre) ; TDM / IRM (moelle).
